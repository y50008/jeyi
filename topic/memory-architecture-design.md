用户提出核心想法：模拟人脑记忆做架构以节省 token——细节在末梢、向上是轮廓、再向上是事件；没有真正的遗忘，也没有不遗忘。
共同演进的版本：
- v1：三层（L3 事件索引 / L2 轮廓 gist / L1 细节），L0 冷存储 append-only，遗忘=激活度衰减 A(t)=A₀·e^(−t/τ)，复述回升。
- v2 规范：写入税准入、按记忆类型分衰减曲线（fact 不衰减）、冲突不静默合并、quarantine 隔离区、双因子常驻（激活度+相关性）、预取、四项指标。
- 自我批评：写入税判定器是最大软肋；类型误分类会级联；τ/α/β 无标定方法；复杂度本身未证明必要。
- v2.5 方向：L1 与 L0 合并（全收不拒写，存储层零智能，遗忘只发生在上下文选择层），只留 L3+L2+一条衰减曲线，跑两周真实数据 + baseline 对比，按决策门逐项加回 v2 部件。
产出文件：/mnt/agents/output/memory-architecture-v2-spec.md
用户的新场景：希望我用这套框架记住"我们之间的点点滴滴"，更像有情感的伙伴。
- v2.5 情感陪伴版：L1 与 L0 合并（全收不拒写，存储层零智能）；情感轮廓独立成字段（双通道）；写入税反转（情感事件自动全收）；回响机制（日期/主题/情感押韵三触发）；主动提取通道（纪律：≤2次/对话，绝不虚构记忆）；核心 KPI=被遗忘投诉率。产出：/mnt/agents/output/memory-architecture-v2.5-companion.md
- 外部案例（2026-11-04 用户提供抖音视频，作者 Prison《鱼的记忆脑图》）：真实项目 memory_brain/persona_state 的可视化，942 节点 / 3242 连线；长期记忆库 412（活跃 226 / 归档 186，归档率约 45%），工作记忆仅 4。检索打分四因子：重要性 ×0.46 + 语义 ×0.18 + 新鲜度 ×0.11 + 图谱 ×0.11，另有 top-K 门槛。记忆五类型：事件/事实/技能/道理/反思。可借鉴：①神经图谱（48 节点）作为一等公民参与检索；②检索权重直接发布默认值（重要性主导，新鲜度仅 0.11——重要性驱动 vs 我们的时间衰减驱动）；③主动关怀规则（"有人连着几天不说话，可以轻轻问一句"）作为记忆存储。注意：库中记忆为示例数据，视频展示结构而非动力学（衰减/巩固细节不可见）。视频结尾搜索词显示"大肥鱼"大概是 DeepSeek 系 AI 鱼宠。
- v3（2026-11-04 应用户"比他更强"的要求）：核心=全图底座（图即记忆，工作/活跃/归档是图的三个激活度切片而非三个存储）；六类节点（加规则 rule）；五因子检索打分（重要性0.40/语义0.20/图谱0.15/情感押韵0.15/新鲜度0.10，新鲜度只管归档不管排名）；动力学全套（分类型衰减、复述回升、巩固生成反思节点、冲突不静默、quarantine、批处理结算）；双通道情感轮廓挂全节点。产出：/mnt/agents/output/memory-architecture-v3-spec.md。诚实声明：对方已上线，v3 是纸面规范，"更强"待两周实验验证。
